# Демо-проект "Система Бібліотека" (GUI версія)

Цей проект є демонстрацією принципів Об'єктно-Орієнтованого Програмування (ООП) на Java, зокрема **абстракції**, **успадкування** та **поліморфізму**.

На відміну від простої консольної версії, цей проект робить крок у бік **розділення відповідальності (Model-View)**. 
Об'єкти ("Модель") не виводять інформацію про себе в консоль, а повертають її у вигляді рядка. А "Вигляд" (у даному випадку, клас `LibraryGUIDemo`) вирішує, як цю інформацію відобразити — у простому графічному вікні (GUI) за допомогою **Java Swing**.

## 🎯 Ключові принципи та архітектура

1.  **Абстракція (Interface):** `LibraryItem.java`

      * Оголошує "контракт". Будь-який елемент каталогу *зобов'язаний* мати методи `getTitle()`, `getCatalogId()` тощо.

2.  **Успадкування (Abstract Class):** `AbstractLibraryItem.java`

      * Надає **спільну базу** (поля `title`, `catalogId`...) та **базову реалізацію** методів, щоб уникнути дублювання коду в класах-нащадках.

3.  **Поліморфізм (Polymorphism):** `LibraryGUIDemo.java`

      * Ми створюємо єдину колекцію `List<LibraryItem>`.
      * Ми додаємо в неї **об'єкти різних типів** (`Book`, `ReferenceBook`, `JournalIssue`).
      * Ми викликаємо для кожного з них **один і той самий метод** (`item.getDetailsAsString()`), і Java автоматично виконує правильну версію цього методу для кожного об'єкта.

4.  **Розділення Відповідальності (Model-View):**

      * **Модель (Model):** Класи `Book`, `JournalIssue` і т.д. Їхня відповідальність — знати свої дані та підготувати їх у вигляді рядка. Вони роблять це через метод `getDetailsAsString()`.
      * **Вигляд (View):** Клас `LibraryGUIDemo`. Його відповідальність — **показати** дані користувачеві. Він бере рядки від Моделі і розміщує їх у `JTextArea` всередині `JFrame` (вікна).

## 📂 Структура проекту та відповідальність компонентів

Проект складається з 6 файлів:

### 1. `LibraryItem.java` (Інтерфейс)

  * **Відповідальність:** "Контракт". Оголошує два ключові методи для відображення:
      * `void displayDetails()`: (старий) для виводу в консоль.
      * `String getDetailsAsString()`: (новий) для повернення рядка, який буде використаний у GUI.

### 2. `AbstractLibraryItem.java` (Абстрактний клас)

  * **Відповідальність:** Спільна логіка.
      * Містить спільні поля (`title`, `catalogId`, `totalCopies`).
      * Надає **базову реалізацію** для `getDetailsAsString()`, яка збирає інформацію про назву, ID та доступність.

### 3. Конкретні класи (Реалізації)

Усі вони успадковують `AbstractLibraryItem` і **перевизначають (`@Override`)** метод `getDetailsAsString()`:

1.  Вони викликають `super.getDetailsAsString()` (батьківський метод), щоб отримати спільну інформацію.
2.  Вони **додають** до цього рядка свою унікальну інформацію (наприклад, автора, тематику або номер випуску).

<!-- end list -->

  * 🔹 **`Book.java`**: Додає `author`.
  * 🔹 **`ReferenceBook.java`**: Додає `subject` і перевизначає `isLoanable()` (повертає `false`).
  * 🔹 **`JournalIssue.java`**: Додає `publisher` та `issueNumber`.

### 4. `LibraryGUIDemo.java` (Головний клас з GUI)

  * **Що це?** Точка входу в програму (містить метод `main`).
  * **Відповідальність:**
    1.  **Створення Колекції:** Створює `List<LibraryItem> catalog` (Вимога 3).
    2.  **Наповнення Колекції:** Додає в список об'єкти `new Book(...)`, `new ReferenceBook(...)` тощо.
    3.  **Отримання Даних:** Проходить по списку в циклі та викликає `item.getDetailsAsString()` для кожного елемента, збираючи все в один великий рядок `StringBuilder`.
    4.  **Створення "Міні-Дисплею":**
          * Створює `JFrame` (головне вікно).
          * Створює `JTextArea` (текстове поле) і поміщає в нього зібраний рядок.
          * Додає `JScrollPane` (прокрутку), щоб можна було переглядати весь список.
    5.  **Відображення:** Робить вікно видимим (`frame.setVisible(true)`).


## 🚀 Як запустити

1.  Переконайтеся, що у вас встановлено **Java Development Kit (JDK)**.
2.  Збережіть усі 6 файлів (`LibraryItem.java`, `AbstractLibraryItem.java`, `Book.java`, `ReferenceBook.java`, `JournalIssue.java`, `LibraryGUIDemo.java`) в одній директорії.
3.  Відкрийте термінал або командний рядок у цій директорії.
4.  Скомпілюйте всі файли:
    ```
    javac *.java
    ```
5.  Запустіть головний клас `LibraryGUIDemo`:
    ```
    java LibraryGUIDemo
    ```
6.  У результаті на екрані з'явиться графічне вікно ("міні-дисплей") з повним каталогом бібліотеки.
